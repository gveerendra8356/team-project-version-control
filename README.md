# Team Project Version Control

A modular Python utility project for a Git collaboration lab.

## Module summary
Modules: calculator supports addition; text tools supports word counting.

## Run tests
```sh
python -m unittest -v
```

## Workflow
1. Clone the repository and pull main.
2. Create a feature branch for each module.
3. Implement changes and run tests.
4. Stage, commit, and push the module branch.
5. Open a pull request into main and review its diff.
6. Address feedback with additional commits.
7. Merge main into the feature branch and resolve conflicts.
8. Stage resolved files, commit the merge, push, and merge the PR.
